# ArthSathi

ArthSathi (Arth = wealth/finance, Sathi = companion) is an AI-powered, voice-first, multilingual financial companion web app designed for underprivileged and low-literacy users in rural India. It aims to bridge the financial literacy gap by providing accessible, conversational guidance on savings, loans, government schemes, and everyday money management — in the user's own language and through voice interaction, removing barriers posed by limited reading ability or smartphone experience.

## Folder Structure

- `frontend/` — Client-side application (voice UI, multilingual interface)
- `backend/` — Server-side API, AI integration, and data layer
- `docs/` — Architecture diagrams, design decisions, and technical documentation
